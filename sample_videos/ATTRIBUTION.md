# Sample Video Attribution Guidelines

This folder contains local video files used as inputs to validate the YOLO detection, person tracking, and security rules engine pipeline.

## Public / Open Assets Attribution

If you are using the standard testing video `people-detection.mp4` or other clips from Intel's reference datasets, please attribute them as follows:

*   **Source**: [Intel IoT DevKit sample-videos repository](https://github.com/intel-iot-devkit/sample-videos)
*   **License**: Creative Commons Attribution 4.0 International (CC-BY-4.0)

## Guidelines for Campus Demos & Submissions

*   **Final Submission Footage**: For final submissions or official KUET campus demonstrations, it is highly recommended to record your own local campus footage (e.g. at the KUET Main Gate, corridors, or building entries).
*   **Consent and Privacy**: Ensure all individuals visible in any recorded demo videos have consented to their images being used for this project, particularly if screenshots of the dashboard are included in proposals or public reports.
*   **Do Not Commit Videos**: Do not add large raw video files (like `.mp4`, `.avi`, `.mov`) to the Git repository. Keep the folder clean and only commit documentation files like this `ATTRIBUTION.md` and the folder `README.md`.
